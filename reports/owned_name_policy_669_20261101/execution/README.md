`selection.final.json` is the explicit evidence selection. `final-inputs.json` binds that exact selection, its README and the verifier. The default verifier reads archived bytes rather than historical absolute paths or transient Git objects:

```sh
python reports/owned_name_policy_669_20261101/execution/verify.py verify \
  --package reports/owned_name_policy_669_20261101/execution
```

After commit, add `--repository . --require-tracked` to compare every package file with its current HEAD blob. This works after a squash and in a shallow consumer without the old feature objects. `--current-scope` is a separate optional check of selected current maintained paths; future legitimate curation can invalidate that check while historical archive verification continues to pass. A trusted committed package or externally pinned manifest is the integrity anchor; hashes alone are not independent scientific authority.

To inspect a selected original, locate its original path and SHA256 in `manifest.json`, then read the named SHA member from `payloads.tar.gz` or the exact blob path. The selection's graph bindings distinguish recorded-only omissions from archived original bytes.

The final whole-change native review, committed-head/body review and subsequent CI/queue/merge attestations follow package freeze and remain external or in later immutable supplements. Their absence from this archive avoids a circular hash dependency and is not a claim that they have completed.
